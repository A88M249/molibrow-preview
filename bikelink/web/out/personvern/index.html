Personvernerklæring

Sist oppdatert: 7. juli 2025

BikeLink.no driver denne nettbutikken og nettstedet, inkludert all tilhørende informasjon, innhold, funksjoner, verktøy, produkter og tjenester, for å gi deg – kunden – en kuratert og trygg handleopplevelse (“Tjenestene”). BikeLink.no er drevet av Shopify, som gjør det mulig for oss å levere Tjenestene. Denne personvernerklæringen beskriver hvordan vi samler inn, bruker og deler dine personopplysninger når du besøker, bruker eller gjennomfører kjøp eller andre transaksjoner via Tjenestene, eller når du kommuniserer med oss. Dersom det skulle være motstrid mellom våre vilkår og denne personvernerklæringen, gjelder denne erklæringen for innsamling, behandling og deling av personopplysninger.

Ved å bruke Tjenestene bekrefter du at du har lest og forstått denne personvernerklæringen.

Personopplysninger vi samler inn eller behandler

Med begrepet “personopplysninger” mener vi informasjon som identifiserer eller med rimelighet kan knyttes til deg. Dette inkluderer ikke anonymiserte eller avidentifiserte data. Vi kan samle inn eller behandle følgende kategorier av personopplysninger, avhengig av hvordan du bruker Tjenestene, hvor du bor, og som tillatt i henhold til gjeldende lovverk:

  • Kontaktinformasjon som navn, adresse, fakturaadresse, leveringsadresse, telefonnummer og e-postadresse.
  • Betalingsinformasjon som kreditt-/debetkortnummer, kontoopplysninger, betalingsmetode, transaksjonsdetaljer og betalingsbekreftelser.
  • Kontoopplysninger som brukernavn, passord, sikkerhetsspørsmål, preferanser og innstillinger.
  • Transaksjonsdata inkludert varer du ser på, legger i handlekurven, ønsker deg, kjøper, returnerer eller bytter, samt tidligere kjøp.
  • Kommunikasjon du sender til oss, for eksempel via kundeservicehenvendelser.
  • Enhetsinformasjon som nettleser, IP-adresse, enhets- eller nettverksidentifikatorer.
  • Bruksdata som hvordan du navigerer og interagerer med Tjenestene.

Kilder til personopplysninger

Vi kan samle inn opplysninger fra:

  • Direkte fra deg, når du oppretter konto, handler, kommuniserer eller sender inn informasjon.
  • Automatisk, via informasjonskapsler, enheten din eller når du bruker nettstedet.
  • Tjenesteleverandører, som behandler data på våre vegne (betaling, frakt, analyse m.m.).
  • Partnere og tredjeparter i samsvar med gjeldende lov.

Hvordan vi bruker dine personopplysninger

Avhengig av hvordan du bruker Tjenestene, kan vi bruke dataene til følgende formål:

1. Levering og forbedring av Tjenestene

Vi bruker personopplysninger for å:

  • behandle betalinger og fullføre bestillinger
  • administrere og vedlikeholde kundekontoer
  • huske preferanser og anbefale relevante produkter
  • håndtere frakt, retur og bytter
  • sende kontorelatert informasjon og ordreoppdateringer
  • forbedre brukeropplevelsen og optimalisere nettstedet

2. Markedsføring og annonsering

Vi kan sende deg:

  • nyhetsbrev, kampanjer og tilbud på e-post eller SMS
  • målrettede annonser basert på tidligere aktivitet

Du kan når som helst melde deg av markedsføring.

3. Sikkerhet og svindelforebygging

Vi bruker informasjonen til å:

  • beskytte kontoen din
  • oppdage og forhindre svindel eller uautorisert aktivitet
  • sikre trygge betalinger og systemer

4. Kundekommunikasjon

Vi bruker data for å gi support, besvare henvendelser og opprettholde kundeforholdet.

5. Juridiske formål

Vi bruker personopplysninger når nødvendig for å etterleve lovpålagte krav eller håndtere juridiske prosesser.

Hvordan vi deler personopplysninger

Vi kan dele personopplysninger i følgende tilfeller:

  • Med Shopify, som drifter plattformen og tilbyr nødvendige teknologitjenester.
  • Med tjenesteleverandører, som betalingsløsninger, analyseverktøy, kundestøtte, frakt og lager.
  • Med markedsføringspartnere, som tilbyr målrettet annonsering (i henhold til gjeldende lov).
  • Med tredjeparter når du samtykker, som ved bruk av sosiale medier-innlogginger eller fraktinstruksjoner.
  • Med konsernforbundne selskaper.
  • I forbindelse med fusjon, oppkjøp eller virksomhetsoverdragelse.
  • For å overholde lov, inkludert forespørsler fra offentlige myndigheter.

Forholdet mellom BikeLink.no og Shopify

Shopify kan behandle dine personopplysninger som en egen behandlingsansvarlig i visse tilfeller, særlig når deres utvidede tjenester brukes.
Du kan lese mer om dette på:

  • Shopify Consumer Privacy Policy
  • Shopify Privacy Portal (for innsyns- og rettighetsforespørsler)

Tredjepartslenker

Nettstedet kan inneholde lenker til eksterne sider. BikeLink.no er ikke ansvarlig for innhold, sikkerhet eller personvernpraksis på disse sidene. Vi anbefaler at du leser deres personvernerklæringer.

Barns personvern

Tjenestene er ikke ment for barn. Vi samler ikke bevisst inn informasjon fra mindreårige. Hvis ditt barn har delt sine opplysninger med oss, kan du kontakte oss for å få dem slettet.

Sikkerhet og lagring av data

Ingen systemer kan garantere fullstendig sikkerhet. Informasjon sendt over internett kan være utsatt under transport.
Vi lagrer personopplysninger så lenge det er nødvendig for:

  • å tilby Tjenestene
  • overholde lovkrav
  • løse tvister
  • håndheve avtaler

Dine rettigheter

Avhengig av hvor du bor, kan du ha rett til:

  • innsyn i egne personopplysninger
  • å få data slettet
  • å få informasjon korrigert
  • dataportabilitet (få kopi eller overføre data til tredjepart)
  • å reservere deg mot markedsføring
  • å protestere mot visse typer behandling
  • å trekke tilbake samtykke der det brukes som behandlingsgrunnlag

Du kan utøve dine rettigheter ved å kontakte oss.

Vi kan be om identitetsbekreftelse før forespørsler behandles.

Internasjonale overføringer

Vi kan overføre personopplysninger utenfor EØS eller Storbritannia.
Når vi gjør dette, bruker vi godkjente overføringsmekanismer som EUs standardkontrakter, med mindre mottakerlandet er forhåndsgodkjent av EU for å ha tilstrekkelig personvern.

Endringer i personvernerklæringen

Vi kan oppdatere denne erklæringen ved behov. Endringer publiseres med oppdatert dato.
